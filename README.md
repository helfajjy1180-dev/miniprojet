# Mini-projet Python – Gestion d'une boutique

## 1. Description du projet

Ce projet consiste à développer une application Python pour gérer les produits et les clients d'une boutique.

L'application utilise la programmation orientée objet (POO) et deux bases de données : SQLite et MySQL.

Elle permet d'ajouter, d'afficher et de rechercher des informations, ainsi que de modifier le prix des produits.

## 2. Fonctionnalités

- Ajouter un produit.
- Afficher tous les produits.
- Modifier le prix d'un produit.
- Ajouter un client.
- Afficher tous les clients.
- Rechercher un client par email.
- Choisir entre SQLite et MySQL.

## 3. Résultat du projet

Après l'exécution, l'application affiche un menu interactif dans le terminal.

L'utilisateur peut choisir une base de données et effectuer les différentes opérations de gestion.

Les données ajoutées sont enregistrées dans la base de données sélectionnée et peuvent être consultées ultérieurement.
